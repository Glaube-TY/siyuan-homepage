# 全局性能与结构优化

## 目标与边界

本阶段优先缩短“思源启动 → 插件可用 → 主页首屏可见”的关键路径，同时降低主页长时间打开后的定时器开销。不改变设备视图事务的一致性边界，不用“少校验一次”换取表面速度。

## 已实现

1. 插件 `onload` 只同步完成必需注册；划词 AI 设置改为独立异步加载，不再阻塞设备身份与主页入口。
2. `onLayoutReady` 中的通知首轮扫描和机器人 Provider 初始化改为空闲期启动，每个后台能力独立隔离失败，卸载时可取消未执行任务。
3. 主页组件文档仍保留“初读 + 切换前复核”，但从逐个串行改为最多 4 路的有界并发，避免大布局将 API 延迟线性累加。
4. 横幅设备配置、横幅资源与背景资源改为并发解析。
5. 首屏加载条由真实阶段驱动：会员能力、持久区域、配置/组件数据、当前分区、网格、主题绘制。不再用无限循环动画伪装初始进度。
6. 飘落和鼠标特效延后到首屏可交互后的空闲期。
7. 12 种时钟展示共享一个与整秒对齐的计时源；页面隐藏时自动暂停，最后一个订阅者销毁后自动释放。经典时钟原有的 50ms 刷新被移除。
8. 新增最近 80 条的内存性能样本，覆盖插件启动、`onLayoutReady` 和主页首屏，供后续设置页诊断面板复用。

## 第二阶段：主包与共享基础设施

1. 11 个图表入口统一使用 `src/utils/charts/echarts.ts`，只注册项目实际使用的图表、组件和 Canvas 渲染器；保留折线、柱状、饼图、散点、热力日历、词云、甘特图、缩放、标记线和导出图片能力。
2. 图片轮播由 `swiper/element/bundle` 改为官方按需模块注册。保留自动播放、无障碍、导航、分页以及 slide、fade、cube、coverflow、flip 全部已有切换效果，并将对应 Shadow DOM 样式显式注入。
3. 音乐播放器改用 Howler core 构建；项目未使用的空间音频插件不再进入主包，播放、暂停、进度、音量、静音和流媒体能力不变。
4. 有界并发实现收敛到 `src/utils/async/mapWithConcurrency.ts`。Agent 原有业务目录中的历史转发入口已删除，主页与 Agent 直接复用同一个通用实现。
5. `verify:performance` 增加依赖入口契约，防止以后误把完整 ECharts、Swiper bundle 或 Howler 空间音频重新引入。
6. 任务、复习、强化日记和纪念日通知调度器复用启用检查时已读取的设置快照：定时扫描由每轮两次存储读取降为一次，设置变更触发的“检查 + 立即扫描”由三次降为一次。

生产构建的 `dist/index.js` 从本轮优化前的 7,071,098 字节降至 6,657,990 字节，减少约 413 KB（约 5.8%）；gzip 从约 2,156.58 KB 降至约 2,025.33 KB，减少约 131.25 KB。CSS 体积未变化。

## 控制台信息

- `Noto-COLRv1.woff2` 的 `[Intervention] Slow network` 来自思源本体 `/appearance/fonts/` 字体加载，项目内没有引用该字体。这是 Chromium 的慢网络回退提示，不是插件异常；插件不覆盖思源全局字体。
- 木鱼警告的真实原因是 2026 年数据中混入了已退役的 `legacy-daily` 记录。当前代码只剔除这一种明确退役记录，不将它转换成新数据；其他未知损坏继续严格报错。

## 构建限制

当前思源插件的 `index.js` 可能通过 data URL / eval 注入，现有构建因此强制 `inlineDynamicImports` 以保证运行稳定。当前没有把 Agent、富文本等拆成外部 chunk。只有在先建立可靠的插件资源 URL 加载器，并覆盖 data URL、桌面端和移动端部署验证后，才可以改变这条单文件边界；不能用破坏现有加载方式来换取表面上的首包数字。

## 后续开发约束

- 新增图表必须从共享 ECharts 入口导入；新增图表类型或组件时只在该入口注册一次。
- 第三方库优先使用官方模块化入口或核心构建，禁止无理由导入 `bundle` / 全量入口。
- 通用能力放在 `src/utils`，业务目录不得复制实现或保留仅供内部使用的旧路径转发。
- 启动关键路径只做主页可用前必须完成的工作；非关键能力使用现有空闲调度并在卸载时取消。
- 数据一致性校验、写后读验证、权限、安全清洗与失败隔离不得作为性能优化对象删除。
- 每次性能改动先跑 `pnpm verify:performance`，交付前跑类型检查、Lint 和生产构建；构建仍必须保持单文件可运行。

## 收尾审计结论

2026-08-12 已完成全仓收尾审计。现有直接依赖均有实际调用；剩余定时器均对应正在运行的通知、倒计时、专注、音乐或设置页任务，并具备停止或销毁路径。`tyme4ts`、Agent SDK、DOMPurify、JSZip、富文本和音乐元数据等体积来源承载现有功能，当前不存在不改变功能即可安全删除的等价实现。

全局性能优化标记为完成。后续只在真实性能样本暴露新瓶颈，或建立并验证插件资源加载器后继续优化；不再为了体积数字进行无证据重构。
