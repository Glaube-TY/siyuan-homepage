# 科技主题设计契约

| 契约 | 约束 |
| --- | --- |
| 作用域 | 仅 `data-hp-theme="builtin.technology"` 下生效 |
| 数据与布局 | 不创建、删除、移动或重设任何主页组件 |
| 基础结构 | 复用现有共享主题组件和持久化区域 |
| 组件适配 | 通过 Widget Presentation manifest 按类别与变体统一适配 |
| 原生形状 | `PicCaro` 与 `timedate.dial` 不套 HUD 壳层 |
| 色彩 | 深蓝黑底、青色主强调、琥珀小面积次强调 |
| 装饰 | 仅低对比网格、静态扫描线与角点，不生成假仪表数据 |
| 响应式 | 使用 `@container hp-homepage`，不以设备视口推断组件空间 |
| 可访问性 | 保留键盘焦点，支持减少动画与强制颜色模式 |
| 会员 | 主题访问级别为 VIP，经典主题始终免费且排序第一 |

验证标准：主题可被注册与安全回退；切换不改变布局数据；设置中心无预览图片；主题名称统一；生产构建不引入远程视觉资源。
