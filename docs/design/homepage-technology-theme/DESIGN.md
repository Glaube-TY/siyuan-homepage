# Visual Theme & Atmosphere

深海 HUD 控制台。页面像一套安静运行的信息仪表，而不是高亮霓虹游戏界面：深蓝黑底、青色信息光、少量琥珀重点、细网格与弱扫描线。科技感来自信息秩序和精确边界，不照搬参考图中的雷达、圆盘或虚构数据。

# Color

- 页面底色：`#04131f`。
- 面板：`#092a36` 附近的半透明深青。
- 主强调：`#55ece9`，用于焦点、活动状态和关键操作。
- 次强调：`#f2c477`，只用于少量重点和变体。
- 正文：`#d9fbfc`；次级文字：`#83b6bd`。
- 所有颜色通过 `--hp-tech-*` 语义 token 注入，组件不得各自维护独立色表。

# Typography

沿用思源与插件现有字体栈，避免新增字体文件。标题使用更强字重与轻微字距，正文保持普通字重；数字和状态依靠层级与颜色区分，不强制全局等宽字体。

# Spacing & Grid

以 4px 为最小节奏，主要间距使用 8/12/16/24。背景网格为 24px，仅作低对比度空间参照。面板内边距随主页容器宽度收缩，不依赖视口宽度。

# Layout & Composition

继续复用主题引擎既有的身份、状态、操作、横幅、分区、工作区和页脚区域。桌面顶部为三列控制条；窄容器自动换成两列或单列。主题只改变呈现，不改变组件数据、数量、顺序、大小和分区。

# Components

普通内容组件使用 `technology.hud` 壳层：细青色边界、极小圆角、角点提示和深色面板。组件按既有呈现类别统一适配，并提供青、琥珀、蓝三种克制变体。轮播图与仿真时钟等自带完整视觉形状的组件排除外层面板，避免重复包裹。

# Motion & Interaction

悬停只做 1px 上浮和边界增强，焦点使用清晰青色轮廓。扫描线保持静态。系统启用减少动画时关闭主题过渡和位移；高对比模式使用系统边界色。

# Voice & Brand

用词简短、直接、像控制台状态，不堆叠英文缩写或伪技术参数。主题中心统一使用单词名称：经典、卡片、手绘、纸质、简洁、科技。

# Anti-patterns

- 不复制参考图的雷达、仪表盘或装饰性假数据。
- 不使用大面积刺眼霓虹、持续闪烁、发光文字或高频动画。
- 不给每个组件单独写适配分支，优先使用呈现类别与展示变体契约。
- 不污染思源全局变量或主题外弹窗。
- 不为预览图维护一套与真实主页不一致的假界面。
