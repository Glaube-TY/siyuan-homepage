# UI、组件与主题开发规则

## 适用范围

修改 Svelte 组件、CSS/SCSS、布局、主题、组件呈现类别/变体、响应式行为或无障碍时读取本文件。非 UI 任务不要加载本文件。

开始前先读本文件，并检查现有主题引擎、Widget Presentation manifest、共享区域、token 和实际主题实现；不要另建平行布局、主题或组件适配层。

## 通用边界

- 样式只能挂在插件根容器、功能容器或组件局部类上。禁止无作用域覆盖 `body`、`:root`、`.layout`、`.b3-*`（包括 `.b3-button`、`.b3-text-field`、`.b3-switch`）或其他插件。
- 复用思源变量前确认它真实存在且稳定；不确定的 `--b3-*` 必须提供 fallback。自定义 token 使用插件专属前缀。
- 主题只改变呈现，不改变组件数据、布局、顺序、大小、持久化区域或业务状态。优先按呈现类别和稳定变体适配，不为每个业务组件添加特判。
- 保留键盘焦点、减少动画和强制颜色模式；响应式布局按容器空间处理，科技主题使用 `@container hp-homepage`，不能用设备视口猜测组件空间。
- 不生成雷达、仪表盘、扫描线数据等假业务信息，不使用远程视觉资源，不维护与真实主页不一致的预览界面。原生完整形状组件不强行套统一壳层。

会员视觉规则：普通插件 UI 中唯一的会员标识是 `PremiumMark`，不使用 Emoji Crown 或文字 badge。凡是用户可选择的 Premium 能力，都要在选择点逐项标识；父级 Premium 不取消子级可选择 Premium 项的标识，混合免费/Premium 控件必须在选择前显示各 Premium 选项。`PremiumMark` 只提供视觉信息，真正的权限仍由 entitlement/runtime 控制。

## 组件呈现契约

主题只识别稳定的呈现类别，不按业务组件名称堆叠选择器：

| 类别 | 含义 | 现有示例 |
| --- | --- | --- |
| `collection` | 重复条目、卡片或时间线内容流 | 最近文档、收藏、任务、最近日记 |
| `metrics` | 少量关键数字和短标签 | 天气、统计卡片 |
| `visualization` | 图表、热力图、数据画布或查询结果 | 热力图、SQL、图表 |
| `editorial` | 阅读、书写或长文本 | 自定义文档、便签、每日一句 |
| `media` | 图片、封面或播放内容 | 图片轮播、音乐播放器 |
| `control` | 单一目标明确的交互工具 | 专注计时、倒计时、赛博木鱼 |
| `embedded` | 外部页面或隔离运行时 | 网页浏览器 |
| `workspace` | 多区域、多状态的复合工作台 | 固定资产、强化日记、记账、AI 知识库 |
| `intrinsic` | 自带完整造型，不适合强制包卡片 | 仿真时钟、黄历 |

展示变体只登记会改变视觉骨架的稳定模式（例如标准/紧凑/沉浸、经典/仿真表盘）；筛选、颜色、排序等业务配置不进入主题变体。主题解析顺序固定为“变体 → 组件覆盖 → 类别 → 通用回退”。

## 科技主题

- 使用现有 `--hp-tech-*` 语义 token；视觉基调是深蓝黑、青色主强调和少量琥珀重点，低对比网格/静态装饰不能承载虚构数据。
- 普通内容组件按 `technology.hud` 和既有呈现类别适配；`PicCaro`、`timedate.dial` 等自带完整形状的组件不套 HUD 壳层。不要新增按业务名称分支。
- 主题访问级别、经典主题优先、名称、预览和无远程资源要求以设计契约为准；切换主题不得改变布局数据。
- 需要具体色值、间距、动效和主题契约时，再读取 [`docs/design/homepage-technology-theme/`](../design/homepage-technology-theme/)，不要把设计数值复制到根规则或每个组件。

## 验证

主题相关改动运行 `pnpm verify:homepage-theme`；涉及 Svelte/TypeScript 或打包边界时再运行 `pnpm typecheck` 和生产构建。只改其他领域时不要运行这些检查。
