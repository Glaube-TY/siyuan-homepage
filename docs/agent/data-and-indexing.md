# 数据、SQL 与索引开发规则

## 适用范围

修改业务数据、视图配置、SQLite/SQL、主页索引、JSON 存储、同步 scope、文件 schema/version 或数据迁移时读取本文件。当前索引来源和用户入口已在本文件记录。

## 数据与视图

- 业务数据由统一服务读写并跨设备共享；PC 视图按物理 PC scope 隔离，移动视图使用固定 `mobile-shared` scope。
- 前端只能读写获授权的 `scope + surface` 目录，不得扫描、回退、合并或修改其他设备配置；组件只保存实例和展示参数，不复制业务数据。
- 读取失败、目录异常、文件损坏或状态未知不得解释为空数据、对象不存在或规则已满足。损坏数据不得静默归一化、覆盖或用默认值保存回去；按当前 schema/version 读写并在写后回读验证，必要时做版本/CAS 校验。
- 单个数据域或索引失败只影响自身，不能清空主页、覆盖其他域或阻止无关域继续工作。索引版本升级按当前数据重建，不迁移旧属性/旧格式。
- 例外：`favorites-index.json` 属于用户主动维护、无法从当前文档完整重建的收藏业务状态；已知历史文件 schema 必须保持只读兼容，并在真实写操作时安全升级。不得因版本升级把合法旧收藏解释为空，也不得要求用户重新收藏。这不代表恢复旧文档属性迁移。

## 主页索引目标

- 主页组件只读插件当前本地索引，索引不存在时可以创建空索引；需要从当前文档重新生成时，必须由用户在“主页设置 → 检索管理”中手动重建。
- 不读取或迁移旧文档属性；空态只引导当前刷新/重建操作，不恢复旧属性迁移入口。

## SQL

- 禁止对 `blocks.content`、`blocks.markdown`、`blocks.fcontent` 使用 `LIKE '%关键词%'` 做正文搜索；`LIMIT`、分页或少选字段不能消除全表扫描。
- 正文搜索使用已按 `siyuan_case_insensitive` 分词的 `blocks_fts MATCH` 或思源官方分页搜索 API，不另建 `blocks_fts_case_insensitive`。
- 结构性判断用窄范围条件（如 `subtype`、`root_id`）后解析；`path`、`ial`、`tag`、`bookmark` 等元数据字段的 `LIKE` 必须限定业务范围、转义输入、有结果上限，并确认不会扫描正文。
- Agent SQL 工具同样遵守这些限制；违规只读 SQL 应拒绝并提示 FTS 或更窄的结构化条件。

## 本地索引与文件完整性

- 组件展示只读当前本地索引；索引为空时不能在后台触发全库 SQL，只有用户明确重建才执行可感知的全量查询。
- 查询必须经过当前 `checked/manual-index` 受控入口，限制表和结果数；增量只查询近期变化或已有索引中的 ID。单个索引失败只记录自己的 `*IndexStatus`。
- 索引必须校验 schema/version/根结构；损坏索引不得当空索引或静默覆盖。使用受控 API 写入并回读验证。
- 目录创建异常不能成为静默丢失写入的理由；在当前思源内核允许时继续尝试当前文件写入，并保留 checked API 的写入和回读行为。
- 当前索引维护入口是“主页设置 → 检索管理”；组件空态只引导当前刷新/重建操作，不恢复旧属性迁移入口。

当前索引来源和维护方式：

| 索引 | 来源 | 维护 |
| --- | --- | --- |
| 收藏文档 | 当前收藏操作 | 刷新失效文档，用户重新收藏 |
| 复习文档 | 当前复习计划操作 | 刷新失效文档/块，用户新增复习计划 |
| 任务管理 Plus | 当前任务块 | 增量刷新或用户手动全量重建 |
| 热力图 | 当前文档更新时间 | 增量刷新或用户手动全量重建 |
| 统计卡片 | 当前文档与块统计 | 增量刷新或用户手动全量重建 |
| 强化日记 | 带官方 `custom-dailynote-YYYYMMDD` 属性的日记 | 增量刷新或用户手动全量重建 |
| 强化日记项目/记录 | 当前项目节点和记录 | 增量刷新或用户手动全量重建 |

唯一入口提供全部索引刷新、全部索引重建、单项刷新/重建，以及最近状态、时间、处理数量和错误信息。SQL 必须经过当前 checked/manual-index 入口；目录创建异常不能成为静默丢失写入的理由。

## 日期

业务日期按本地年月日计算，禁止用 `toISOString().slice(0, 10)` 代替本地日期。涉及周期、去重或计划时，使用稳定的业务发生键，不用临时文本拼接猜测状态。
